    무료 API 키 발급 방법

    1. 구글 AI 스튜디오에 접속하고 로그인합니다.
    2. 화면 왼쪽 메뉴에서 'Get API key'를 클릭합니다.
    3. 화면 중앙의 'Create API key' 버튼을 누릅니다. (새 프로젝트 생성)
    4. AIzaSy... 로 시작하는 긴 비밀번호가 생성되면 복사합니다.
    5. 이 웹사이트 화면 상단 🔑 입력칸에 붙여넣고 [저장]을 누릅니다.

    ⚠️ 주의: 발급받은 키는 본인의 비밀번호와 같습니다. 타인에게 공유하지 마세요!
